# 原生科学交互 UI 升级路线

[English](../en/ROADMAP.md) · [目录](README.md)

状态：**后续开发计划，未实现功能不得算入 0.2.0。**日期：2026-10-20。本轮只交付完整双语文档；不擅自把规划写成已发布 API。

## 1. 产品目标与“原生支持”定义

MiQroForge Desktop 本身提供材料计算、计算化学、量子计算、计算生物的交互组件。用户安装／升级 Desktop 后即可使用；不需要安装 skill、MCP 插件、浏览器扩展或单独启动可视化站点。

组件可以在实现层模块化并按需加载，但必须纳入正式安装包、默认注册表、数据协议、主题、可访问性、状态恢复与验收。不能用生成 HTML、静态截图或跳转第三方网页代替专业原生交互。计算执行继续使用 Desktop 已有能力；UI 在其上支持参数输入、结构编辑、可视化、选择联动、任务控制和结果追溯。

## 2. 升级阶段

| 阶段 | 交付目标 | 完成门槛 |
| --- | --- | --- |
| R0 文档与基线 | 当前双语使用／开发手册、完整签名参考、共用代码示例 | 中英文对应、链接和示例可检查、区分现有与规划 |

| R2 四领域首批原生组件 | 下表的材料／化学／量子／生物核心交互 | 每个领域有数据→交互→Host→更新→恢复闭环 |

R1 先做，R2 的四个领域按统一标准实现。不能只完成其中一个领域就宣称支持全部科学 UI。此路线不承诺未经测量的工期或“所有未来算法”覆盖；覆盖以版本化的组件矩阵和验收 fixture 为准。

## 3. R1：所有领域共用的原生能力

### 数据与状态

- 科学数值：单位、量纲、有效位、缺失值、不确定度、参考值和精度元数据。
- 科学数据集：稳定 ID、schema 版本、列定义、来源、内容哈希、任务／结果身份和授权数据引用。
- 坐标与选择：原子／键／残基／帧／曲线点／qubit／gate 的稳定标识；多视图选择不依赖屏幕像素。
- 复数、矩阵、张量、系列、体数据、轨迹和序列的标准表示；禁止静默丢虚部、单位或维度。
- 状态分层：可恢复的相机、选择、帧、筛选；Host 权威任务／计算状态；受控的参数草稿与提交版本。
- 大数据 resolver：分页、范围／分块请求、取消、缓存预算、过期与权限反馈；不向 Artifact 填大文件 bytes。

### 共用组件

建议名称只是设计占位，不是现有导出：

| 组件族 | 原生交互 |
| --- | --- |
| ScientificValue / UnitInput | 数值／单位输入、精度和范围检查、显式转换、复制 |
| ScientificTable | 单位列、排序、筛选、行选择、分页、导出 |
| ScientificPlot | 缩放／平移、对数轴、参考线、选点／刷选、误差与多曲线 |
| ParameterPanel | 参数依赖、约束、重置、草稿、差异与提交确认 |
| TaskPanel | 阶段／进度／日志、取消／重试／结果跳转；权限由 Host 执行 |
| ResultCompare / Provenance | 结果叠加、方法与参数差异、来源／版本、单位一致性检查 |
| ArtifactWorkspace | 多视图布局、选择联动、状态恢复、可复现实例和导出 |

## 4. R2：四领域首批组件

| 领域 | 必需组件 | 必需交互和数据规则 |
| --- | --- | --- |
| 计算材料 | 晶体／周期结构视图、晶胞编辑、收敛图、能带／DOS 视图、计算参数面板 | 旋转／缩放／原子选取／距离角度；分数与笛卡尔坐标明确转换；超胞预览；能量参考、k 路径、自旋和投影说明；从 Host 读取真实结果 |
| 计算化学 | 分子视图／编辑器、几何与约束编辑、振动／光谱视图、反应能量曲线 | 原子／键选择和编辑；键级、电荷、多重度检查；构型切换、测量；模式播放与峰联动；能量单位和参考一致 |
| 量子计算 | 量子电路编辑器、参数面板、态／测量结果视图、Bloch 球、后端映射面板 | qubit／classical bit 编排、门拖放、控制／测量／参数编辑、撤销重做；基态顺序和复振幅明确；shots 分布、误差、执行状态；模拟／硬件执行经 Host |
| 计算生物 | 蛋白质／复合物视图、序列／残基视图、配体／结合位点面板、基础轨迹与结果曲线 | 链／残基／原子选取、表示切换、序列与 3D 联动、测量；配体／口袋选择；帧播放与选点联动；稳定标识与来源完整 |

### 每个组件的交付要求

1. 明确数据 schema、单位／坐标／索引约定及兼容版本。
2. 拥有真实可操作的选择、编辑或视图控制，不能只有结果截图。
3. 交互产生结构化事件；提交／重算／导出调用受控 Host 动作。
4. 保存并恢复其可恢复状态；更换数据时不把旧选择应用到新结果。
5. 有空、加载、无权限、非法、失效、失败、取消和资源不足状态。
6. 有对应 Prompt/spec、Gallery、API 中英说明、键盘操作和验收数据。

## 5. R3：领域高级 UI

| 领域 | 后续组件与交互 |
| --- | --- |
| 材料 | 电荷／自旋／轨道体数据与等值面、切片；声子色散／模式；弹性张量；相图／状态方程；缺陷／表面／反应路径结果联动 |
| 化学 | 分子轨道与电子密度、构象集合、势能面／反应坐标、振动动画、光谱叠加与峰归属、反应网络 |
| 量子计算 | 密度矩阵／复杂矩阵、纠缠与关联视图、参数扫描／优化收敛、噪声模型、拓扑／编译映射、运行批次与结果对比 |
| 生物 | 大轨迹分块播放、接触图、RMSD／RMSF 等结果视图、结构叠合、序列比对、相互作用网络、自由能／集群结果视图 |

所有统计／科学结论必须说明来源：Host 已计算的数据，或组件明确声明的本地计算。不能把抽样、插值、坐标转换或降精度结果伪装成原始结果。具体算法和约定必须随 schema 文档化并有数值验收。

## 6. R4：Desktop 内置与交付验收

- 安装包自带注册、渲染代码、字体、shader／worker 等资源，避免必需 CDN。
- 在 Desktop 现有会话和任务体系中嵌入；用户无需知道插件包、模型内部提示或 skill。
- 区分“离线查看本地结果”与“远程计算／服务需联网”，不能用外部云页面作为唯一展示入口。
- 真实服务：参数编辑→Host 审批→任务→进度→结果→交互→保存／恢复／导出。
- 测试文件／任务／会话权限、取消、重复操作幂等、错误降级；禁止暴露任意 IPC／文件系统。
- 双主题、键盘、窗口尺寸、WebGL 不可用、低内存、长任务与大型数据预算；报告硬件／规模／延迟，不写无证据性能承诺。
- 固定数据做语义断言和截图差异；结构／曲线／电路／选择事件均可追溯。
- 每一版发布中英同内容的组件矩阵、迁移说明和真实 Desktop 验收记录。

## 7. 接下来实际执行顺序

1. 提交本轮双语文档与可检查示例，保留 0.2.0 的已验收二进制。
2. 定义 R1 数据／选择／动作契约和科学数值／表格／曲线／参数／任务组件。
3. 开发 R2 四领域组件；统一注册并嵌入 Desktop 原生页面。
4. 对每个领域完成至少一条真实业务闭环，同时完善科学数据正确性检查。
5. 进入 R3 高级能力，再通过 R4 的整体原生交付门槛；未完成项目持续标为规划。
